# Roadmap

Current release: 0.1.0-alpha.2, one owner per installation.

1. Installation feedback: five independent users connect one project without maintainer help.
2. One Needs you inbox for failing builds, chats waiting for input and upcoming renewals.
3. Changes since last visit, with source links and explicit freshness.
4. Better project/chat linking and supported adapters for more app versions and operating systems.
5. Optional reminder delivery and an easier private-cloud provisioning flow.

These are proposals, not completed features. Multi-user hosted accounts require a separate isolation and authorization design before implementation. No release dates are promised.
