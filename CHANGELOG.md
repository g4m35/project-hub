# Changelog

## 0.1.0-alpha.1

Initial self-hosted alpha:

- Empty first run, fictional demo, guided local setup and configuration checks.
- Connected stack map, GitHub issues/PRs/Actions, Vercel deployment polling and optional events.
- Optional read-only Codex/T3 chat metadata with offline detection and explicit privacy opt-in.
- Manual subscription amounts, currency and due dates.
- Configurable private cloud deployment for one owner, with encrypted provider credentials and signed machine endpoints.

See docs/roadmap.md for proposed features and docs/cloud.md for deployment requirements. The local setup needs no cloud account. The optional cloud path needs your own provider credentials and an email-delivery verification.
